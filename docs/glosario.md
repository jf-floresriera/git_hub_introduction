# Glosario

[Volver al README](../README.md)

| Término | Significado |
|---|---|
| **Repositorio** (*repo*) | Carpeta de un proyecto con todo su historial de versiones |
| **Commit** | Versión guardada: una foto de los cambios con autor, fecha y mensaje |
| **Hash** o ID | Código único de cada commit (`3f2a1c9...`) |
| **Staging** / área de preparación | Lugar intermedio donde se eligen los cambios del próximo commit |
| **Rama** (*branch*) | Línea de trabajo independiente; permite experimentar sin afectar `main` |
| **main** | Nombre habitual de la rama principal (antes `master`) |
| **HEAD** | El commit en el que estás parado |
| **Merge** | Unir los cambios de una rama en otra |
| **Conflicto** | Dos cambios sobre las mismas líneas que Git no puede unir solo |
| **Remoto** (*remote*) | Copia del repositorio en otro lugar, normalmente GitHub |
| **origin** | Nombre por defecto del remoto principal |
| **Clone** | Descargar un repositorio remoto con todo su historial |
| **Push** | Subir commits locales al remoto |
| **Pull** | Traer commits del remoto y unirlos a la rama local |
| **Fetch** | Traer commits del remoto sin unirlos |
| **Fork** | Copia de un repositorio ajeno en tu cuenta |
| **Pull request** (PR) | Solicitud para integrar los cambios de una rama o fork |
| **Issue** | Tarea, error o pregunta registrada en el repositorio |
| **README** | Archivo de presentación del proyecto (se muestra en la portada) |
| **.gitignore** | Lista de archivos y carpetas que Git no debe seguir |
| **Tag** | Etiqueta fija sobre un commit (por ejemplo `v1.0`) |
| **Release** | Versión publicada en GitHub a partir de un tag, con notas y archivos |
| **Stash** | Cajón temporal para guardar cambios sin hacer commit |
| **Rebase** | Reescribir commits para ponerlos encima de otra rama |
| **Token (PAT)** | Clave que reemplaza la contraseña para autenticar Git |
| **SSH** | Método de autenticación con un par de llaves pública y privada |
| **Workflow** | Archivo YAML que define una automatización de GitHub Actions |
| **Markdown** | Formato de texto simple (`#`, `**`, `-`) que GitHub muestra con estilo |
